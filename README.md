# Plate Layout Planner

一个无外部依赖、浏览器本地运行的孔板布局工具。当前支持 6、12、24、96、384 孔板，可逐孔点选、鼠标框选、Shift 连续选择，为孔位添加任意文本或数值参数，并按条件批量计算。

## 运行

直接双击 `index.html` 即可使用。也可以启动本地静态服务器：

```bash
npm run serve
```

然后访问 <http://127.0.0.1:4186/>。

## 选择方式

- 单击圆孔：切换该孔的选中状态。
- 鼠标拖动：框选与选择框相交的孔；按住 Ctrl/⌘ 可叠加框选。
- Shift 单击：从上一个锚点到当前孔，按从左到右、从上到下的板序连续选择。
- 全选、反选、取消选择：位于孔板上方。

## 参数与计算

- 默认提供样本、处理、剂量、时间点、重复和原始值；所有维度都可重命名、改类型、删除或新增。
- 给所选孔赋值时，只会应用已勾选的维度。
- 批量计算支持条件筛选，以及乘、除、加、减；右侧操作数可以是固定数值或另一个数值维度。
- 计算只处理可解析的数值。缺失值、非数值和除零会跳过并汇总提示。

## 数据与导出

- 项目自动保存在浏览器 `localStorage` 中，不上传网络。
- CSV：当前孔板的完整逐孔表，包含所有参数维度。
- SVG：当前着色方式下的矢量孔板图。
- JSON：包含全部五种板型、参数定义与计算记录，可再次导入恢复。

## 测试

```bash
npm test
```

测试覆盖孔位生成、Shift 连选、矩形选择、条件计算和除零处理。

## 科研使用边界

该工具负责布局、标签与确定性算术，不替代实验设计审查或仪器软件校验。导出后应复核孔号、单位、处理条件和计算维度；探索性计算不应直接解释为生物学或临床结论。
