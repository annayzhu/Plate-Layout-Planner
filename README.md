# Plate Layout Planner

一个无外部依赖、浏览器本地运行的孔板布局与配液规划工具。当前支持 6、12、24、96、384 孔板，可逐孔点选、鼠标框选、Shift 连续选择，为孔位添加任意文本或数值参数，并基于当前孔板范围计算配液体系。

## 运行

直接双击 `index.html` 即可使用。也可以启动本地静态服务器：

```bash
npm run serve
```

然后访问 <http://127.0.0.1:4186/>。

## 选择方式

- 单击圆孔：只选择该孔；Ctrl/⌘ 单击可逐个增减选择。
- 鼠标拖动：框选与选择框相交的孔；按住 Ctrl/⌘ 可叠加框选。
- Shift 单击：从上一个锚点到当前孔，按从左到右、从上到下的板序连续选择。
- 单击孔板空白处：取消当前选择。
- 全选、反选、取消选择：位于孔板上方。

## 参数

- 默认提供样本、处理、剂量、时间点、重复和原始值；所有维度都可重命名、改类型、删除或新增。
- 给所选孔赋值时，只会应用已勾选的维度。

## 配液计算

侧边栏的“配液计算”打开宽抽屉，第一版包含四个模块：

- 基础常规配液：C1V1 母液稀释，支持总体积或每孔体积 × 孔数。
- 转染体系配液：支持 RNAiMAX、Lipofectamine 3000、质粒与 siRNA 共转染，以及自定义单管/多管体系；可设置多个目的物、正向/反向转染、分组角色、分组余量、公共 Master Mix 和经确认后应用的中间工作液。
- 连续梯度稀释：固定倍比或指定范围，支持直接配液和逐级稀释；逐级模式会从末级向前累计下游转移量，确保每级转出后仍保留目标体积。
- 药物浓度梯度配液与排板：每种药物可独立设置生成方式、加药体积、溶剂和母液溶剂比例；支持 vehicle 对照、复孔分散、避开边缘孔和多板容量建议。

默认余量为 10%，默认最小可靠移液体积为 1 µL。配方可保存到当前项目；浏览器本地配方库支持加载、复制修改、删除以及 JSON 导入/导出，内置配方保持只读。药物模块不进行 IC50 拟合、药物联合或协同作用分析。

板关联模块的孔数始终来自当前选择范围并显示为只读。如需改变孔数，应关闭配液抽屉后重新选择孔位；再次打开时，各模块尚未保存的输入会在当前页面会话中保留，只有范围与孔数会更新。“恢复默认”仅重置当前模块。

## 数据与导出

- 项目自动保存在浏览器 `localStorage` 中，不上传网络。
- Excel 模板：下载 UTF-8 CSV，双击即可用 Excel 打开；第一列为“孔位”，后续每列为一个参数。
- 表格导入：支持 Excel 保存的 `.csv`、制表符分隔的 `.tsv`，以及原有 `.json` 备份。表头中的 `参数名 (单位)` 会自动拆分名称和单位。
- CSV：当前孔板的完整逐孔表，包含所有参数维度。
- SVG：当前着色方式下的矢量孔板图。
- JSON：包含全部五种板型、参数定义与计算记录，可再次导入恢复。

## 测试

```bash
npm test
```

测试覆盖孔位生成、Shift 连选、矩形选择、基础配液、多目的物/多管转染体系、中间工作液确认、向后累计的连续梯度、药物加药液与溶剂计算、避边排板、多板建议和配方库闭环。

## 科研使用边界

该工具负责布局、标签与确定性配液计算，不替代实验设计审查、厂商说明书或仪器软件校验。实验前应复核孔号、单位、处理条件、试剂比例和计算结果；探索性计算不应直接解释为生物学或临床结论。
