## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for `annayzhu/Plate-Layout-Planner`. See `docs/agents/issue-tracker.md`.

### Issue completion gate

Merging a pull request does not complete an issue. Keep the issue open until every numbered acceptance criterion has current PASS evidence recorded in the issue. Use `Refs #<issue>` in pull requests; do not use an auto-closing keyword. See `docs/agents/acceptance-gate.md`.

### Triage labels

Use the five default canonical triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain documentation layout. See `docs/agents/domain.md`.
