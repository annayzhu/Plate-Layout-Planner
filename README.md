# Plate Layout Planner

一个无外部依赖、浏览器本地运行的多孔板布局与配液规划工具。当前支持 6、12、24、96、384 孔板；一个项目可包含 1–24 块独立物理板，可逐孔点选、鼠标框选、Shift 连续选择，为孔位添加任意文本或数值参数，并基于当前板或多板范围计算配液体系。

## 运行

直接双击 `index.html` 即可使用。也可以启动本地静态服务器：

```bash
npm run serve
```

然后访问 <http://127.0.0.1:4186/>。

## 选择方式

- 单击圆孔：只选择该孔；Ctrl/⌘ 单击可逐个增减选择。
- 鼠标拖动：框选与选择框相交的孔；按住 Ctrl/⌘ 可叠加框选。
- Shift 单击：从上一个锚点到当前孔，按从左到右、从上到下的板序连续选择。
- 单击孔板空白处：取消当前选择。
- 全选、反选、取消选择：位于孔板上方。

## 参数

- 默认提供样本、处理、剂量、时间点、重复和原始值；所有维度都可重命名、改类型、删除或新增。
- 给所选孔赋值时，只会应用已勾选的维度。

## 多板项目

- 板标签位于编辑区上方；可新建空板、复制整板、仅复制参数结构、重排或删除。
- 同规格板也是彼此独立的物理板，板名、参数、孔数据、计算结果和配液方案不会互相污染。
- “全部板概览”以同一个兼容参数统一着色，适合快速检查样本或处理条件的整体分布；精细编辑仍只作用于当前板。
- 撤销优先作用于当前板；新增、复制、重排和删除等项目结构操作使用项目级撤销。

## 配液计算

侧边栏的“配液计算”打开宽抽屉，第一版包含四个模块：

- 基础常规配液：按实验任务分为“固定比例加入试剂”“母液稀释到工作浓度”“从称量物配制溶液”。固定比例模式支持多个试剂、额外加入/最终体系两种比例含义、孔板范围或直接总量、µL/mL 混合单位、余量及小体积工作液建议。
- 转染体系配液：支持 RNAiMAX、Lipofectamine 3000、质粒与 siRNA 共转染，以及自定义单管/多管体系；可设置多个目的物、正向/反向转染、分组角色、分组余量、严格匹配的公共 Master Mix、优化变体和经确认后应用的中间工作液。
- 连续梯度稀释：固定倍比或指定范围，支持直接配液和逐级稀释；逐级模式会从末级向前累计下游转移量，确保每级转出后仍保留目标体积，并可预览后写入当前孔板。
- 药物浓度梯度配液与排板：每种药物可独立设置生成方式、加药体积、溶剂和母液溶剂比例；支持 vehicle 对照、固定对照孔、复孔分散、边缘孔填充和多板容量建议。

默认余量为 10%，默认最小可靠移液体积为 1 µL。配液结果可复制、导出 CSV 或打印为 PDF。配方可保存到当前项目；浏览器本地配方库支持加载、复制修改、删除以及 JSON 导入/导出，内置配方保持只读。药物模块不进行 IC50 拟合、药物联合或协同作用分析。

“跨板配液汇总”可选择当前板、勾选板或全部板。只有配方输入完全相同的方案会合并；系统先把各板基础需求量统一换算为 µL 后相加，再对合计量加入一次统一余量，避免逐板加余量造成重复放大。旧版本保存的方案没有可合并明细时会明确提示重新计算并保存。

板关联模块的孔数始终来自当前选择范围并显示为只读。如需改变孔数，应关闭配液抽屉后重新选择孔位；再次打开时，各模块尚未保存的输入会在当前页面会话中保留，只有范围与孔数会更新。“恢复默认”仅重置当前模块。

## 数据与导出

- 项目自动保存在浏览器 IndexedDB 中，并保留 `localStorage` 镜像用于兼容迁移；数据不上传网络。
- Excel 模板：下载 UTF-8 CSV，双击即可用 Excel 打开；第一列为“孔位”，后续每列为一个参数。
- 表格导入：支持真正的多工作表 `.xlsx`、Excel 保存的 `.csv`、制表符分隔的 `.tsv`，以及 `.json` 工作区备份。XLSX 中每个含“孔位/Well”表头的工作表会作为一块板导入；系统汇总表不会被误当作孔板。
- CSV：当前孔板的完整逐孔表，包含所有参数维度。
- SVG：当前着色方式下的矢量孔板图。
- XLSX：包含实验总览、每块板的独立工作表、跨板配液汇总和按 N 顺序排列的逐步加样清单；执行状态、操作者、时间、实际加入量和备注均留有空列，便于直接在实验台使用。
- JSON：完整工作区备份，包含全部物理板、参数、孔数据、计算记录与已保存方案，可再次导入恢复；旧版单板 JSON 会自动迁移。

## 测试

```bash
npm test
```

测试覆盖孔位生成、Shift 连选、矩形选择、固定比例与基础配液、多目的物/多管转染体系、中间工作液确认、向后累计的连续梯度、药物加药液与溶剂计算、独立多板数据模型、旧数据迁移、跨板配液合并、真实 XLSX 往返和配方库闭环。

## 科研使用边界

该工具负责布局、标签与确定性配液计算，不替代实验设计审查、厂商说明书或仪器软件校验。实验前应复核孔号、单位、处理条件、试剂比例和计算结果；探索性计算不应直接解释为生物学或临床结论。
